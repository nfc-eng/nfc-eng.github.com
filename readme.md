# Nicholas Clement

Personal site. Plain static HTML, generated by a small Node script with no dependencies. The look follows [Teeter](https://trader-tracker-murex.vercel.app): Newsreader and Hanken Grotesk, the same paper and ink colors, and simple cards.

Jekyll is gone. Vercel does not need Ruby. The old custom domain is not referenced anywhere.

## Build

```bash
node build.js
```

That is the command Vercel runs. Output goes to `dist/`.

## Vercel

- Framework preset: Other
- Build command: `node build.js`
- Output directory: `dist`
- Install command: leave the default. There are no packages to install.

`vercel.json` sets the build command, the output directory, clean URLs, and trailing slashes. Internal links are root-relative (`/projects/`, `/writing/...`). Open Graph image URLs stay relative in a local build. On Vercel they become absolute from `VERCEL_PROJECT_PRODUCTION_URL` or `VERCEL_URL`, so no domain is hardcoded.

## Edit

- Projects: the `PROJECTS` list in `build.js`. Link live sites only. Teeter is the one public repo, so it is the only project with a source link.
- Posts: add a markdown file in `posts/` with `title`, `date`, `categories`, and a `permalink` under `/writing/`.
- About: `aboutPage()` in `build.js`. There is a TODO comment in the generated about page.
